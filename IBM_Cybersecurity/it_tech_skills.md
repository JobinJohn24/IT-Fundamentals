### Module 2 Glossary

| Term | Definition |
| --- | --- |
| **Automation** | Automating the configuration, operation, deployment, testing, and management of virtual and physical devices within a network |
| **Cloud** | A network of servers hosted on the internet to store, manage, and process data as an alternative to a local server or personal computer |
| **Database skill** | Knowledge of database types, schemas, administration tasks, and using permissions and roles for limiting access to sensitive data is essential |
| **File Systems** | Organize and secure data within a system |
| **Information Systems** | The combination of hardware, software, data, and human resources to collect, process, store, and distribute information within an organization |
| **Memory Management** | A process affecting system performance and security within operating systems |
| **Networking skills** | It involves understanding the structure and functions of various types of networks, network protocols, OSI models, troubleshooting network problems, network monitoring tools, and network security measures |
| **Programming Basics** | This includes understanding programming languages, data structures, algorithms, secure coding practices, reading and interpreting code, web programming principles, software debugging, and automation scripts |
| **Risk Management** | The process of identifying, assessing, and prioritizing risks, followed by implementing procedures and resources to minimize the impact of these risks |
| **Security operations** | Maintaining and monitoring security infrastructure, carrying out incident response activities, ensuring compliance with regulations, and collaborating with other IT teams to manage security incidents effectively |
| **Threat Management** | A process used by cybersecurity professionals to prevent cyberattacks, detect cyber threats, and respond to security incidents |
| **User Permissions and Roles** | Used within an operating system to limit access to sensitive data |
| **Vulnerability Management** | The continuous discovery, prioritization, and resolution of security vulnerabilities in an organization's IT infrastructure and hardware |
