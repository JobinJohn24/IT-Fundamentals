# Microsoft & Professional Skills: Curriculum Overview

This repository serves as the central hub for tracking progress, developing hands-on labs, and managing technical logs across foundational IT, Cloud Architecture, and Artificial Intelligence engineering for Cybersecurity.

---

## 📂 Directory Index & Core Focus Areas

### 1. 🤖 AI & Machine Learning Track

- **`AI_fundamentals/`**
  - **Focus:** Core theoretical and practical fundamentals of Artificial Intelligence, neural networks, machine learning algorithms, and prompt engineering paradigms.

- **`AI_with_Python/`**
  - **Focus:** Hands-on implementation of AI and machine learning concepts using Python — covering data preprocessing, model training, evaluation pipelines, and applied use cases in classification, regression, and automation workflows.

### 2. 🛡️ Cybersecurity Track

- **`cybersecurity-intro/`**
  - **Focus:** Core security principles including the CIA triad, network security layers, threat intelligence, and basic risk management frameworks.

- **`intro_for_cybersecurity/`**
  - **Focus:** Introductory compliance standards, regulatory landscapes (e.g., GDPR, NIST), and fundamental defensive security toolsets.

- **`IBM_Cybersecurity/`**
  - **Focus:** IBM-aligned cybersecurity curriculum covering security operations, threat analysis, vulnerability management, and enterprise-level defensive strategies aligned with industry frameworks.

- **`js_for_cybersecurity/`**
  - **Focus:** JavaScript applied to cybersecurity contexts — including scripting for automation, understanding browser-based attack surfaces (XSS, CSRF), and building lightweight security tooling and log parsers.

### 3. ☁️ Cloud Architecture Track

- **`google-cloud-cs/`**
  - **Focus:** Google Cloud Platform (GCP) architecture, Identity and Access Management (IAM), Cloud Logging, and securing cloud-native infrastructure.

- **`microsoft-azure-fundamentals/`**
  - **Focus:** Microsoft Azure core components, virtual networking, cloud storage strategies, governance, and AZ-900 certification preparation.

### 4. 💻 IT Infrastructure Track

- **`google-it-professional/`**
  - **Focus:** Systems administration, operating system environments (Linux/Windows), network protocols (TCP/IP, DNS), and automated scripting.

- **`IT_fundamentals/`**
  - **Focus:** Hardware basics, software installation paradigms, database structures, and initial technical support methodologies.

---

## 🚀 Repository Guidelines & Workflow

1. **Log Daily Progress:** For every study block or lab execution, generate a dedicated markdown log using the standard template within the corresponding directory.
2. **Isolate Labs:** Keep configuration scripts, command histories, and code snippets contained inside the module subfolders to maintain modularity.
3. **Track Roadmaps:** Use the root-level README to update macro progress metrics and target certification deadlines.
