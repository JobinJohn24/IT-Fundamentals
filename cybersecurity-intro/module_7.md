*Cybercrime Laws*

*Investigatory Powers Act 2016*

- governing the use of survelliance by public bodies (i.e. police, intelligence servers, and local authorities)
- sections of IPA stipulates the interception of the contents of a communications (e.g. telephone calles, emails, and website details) can be authorized through a *warrant from secretary of state*

*The Computer Misuse Act (1990)*

- 3 stipulations for offenses:
  - unauthorized access to computer materials
  - unauthorized access WITH INTENT
  - unauthorized modification of computer materials -> altering, damaging, or deleting data on a computer WITHOUT permission.
- appended stipulations:
  - DoS: launching DoS & DDoS communcation attacks a criminal offense in the UK.
  - Dual-use tool: criminalizes the creation, supply, or distribution of hardware and software that aids an attack.
    - this is counterintuitive to forensics and cybersecurity experts that investigate systems.

*The Fraud Act 2006*

- defining fraud in 3 ways:
  - false representation
  - failing to disclose information
  - abusing power
- section 11 of the act makes references to electronic fraud & used to prosecute in response to:
  - dishonestly obtaining electronic communication services
  - cloning mobile devices
  - mobile devices reprogramming to interfere with operations or changing the identifying information.
  - breaking encryption on encrypted communication services.

### Recovering deleted files

- specialized software are required to recover the file. 
- Using a file recovery program (*run on a flash memory drive or optical flask*)
  - optical drives: cd/blu-ray/DVD, which uses light & mechanics. The laser shines on the spinning disk, measures how light bounces, and translates them to binary.
  - flash memory drives: USB Thumb drives/SSD, electronic, which uses integrated circuit assemblies to trap or release electrical charges.

*recovering from: lost computer, disk or flash memory drive with confidential data*

- potential vulnerabilty based on:
  - data encryption using forms of strong encryption
  - if there's a password to decrypt it, and is the password known

- microsoft: `restore point` -> features a reversion of your computer to a previous working state (XP or later)
- Mac OS: features `Time Machine` -> which  allows for backups of both file and system configurations.

### Creating a safer / less vulnerable to attack in the future

- basic:
  1. enforcing powerful passwords
  2. automated lockouts
  3. gateway defenses - 
  4. unused data protection - allows for information assets to keep files scrambled and unreadable at rest.
- user access and permisions:
  1. separation of accounts
  2. day-to-day practices: admins should never use root accounts to acccess emails or surf the web.
  3. file permissions: when every file folder contains a operating system metadata, permission allows exactly who can interact with it.
     1. read permission -> file can be edited
     2. write permissions -> file copied
     3. execute permissions -> file excuted as a program
- physical security & hardware control:
  1. disabling ports where using `Data Loss Prevention` software can be used to monitor file copies or disable physical port communications.
  2. hardware lockouts: critical endpoints *NEED* to be chained together to desk or walls using heavy meatl flexible cables.
  3. environmental zoning: network attached storage units & racks should be kept in locked server rooms or secure metal cages bolted to the door.

### Remote Backups

- the use of remote hosting, or data services (e.g. dropbox, gdrive, and one drive) was to keep backups remote from their own devices.

*Offsite Backups*

- specialized facilities where companies hire storage space or machinery to hold it's backups.
- bottleneck: network speed between user and offsite facility.
- e.g. AWS, Microsoft Azure, Google Cloud Platform

*Backup to cloud*

- designed for convenience that allows users to share files between computers rather tahn backup services but offers more security.
- bottleneck: services ar synchronized (if a file is deleted, then the cloud server file is immediately or shortly afterwards be deleted.)

*cloud security*

- zero ability to have the data be 100% secure.
- using encryption to scramble the contents is the *only way* to make data safe.
