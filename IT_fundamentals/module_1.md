## Hardware 

### Components:
- CPU: (brains) involved in all operations run on the compute device. 
- Random access memory: responisble for running applications and holding data during processing.
- Storage: HDD & SSD(faster & modern) - which is used to provide persistent storage for OS, data, and applications. (e.g. whenever you upload your pictures from your digital cameras.)
- Network interface cards - connects the computing device to the outside world. (e.g. how your phone connects to the wifi, connceting to the printers, or a corporate wi-fi.)
    *wired or wireless*
- monitors: built into the device or can be external to it. 
- graphics cards or GCPU's - used to acclerate video operations (gaming, rendering)
   *It can be built-in or on a card*

## Compute components - units

* CPU speeds measured in GHz (e.g. 1.6 GHz)
* memory and storage measuring: giga(gigi), bytes (GB/GiB), or tera (TeBi) Bytes(TB/TiB) (e.g. SSD drives size 10 TB)
* Network interface card speed are measured in megabits/second (Mbps) or Giga bits/second (Gbps) (e.g. 100 Gbps NIC card)

### Software & Operating Systems Overview

## Software 
- instructions that tell the computer what to do.
- applications: operating systems, apps, games

## Operating System
- it manages the hardware resources (CPU, RAM, Disk)
- responsible for running the installed applications
- handles files and permissions (access permissions for certain files)
- provides a UI (GUI OR CLI)
- GUI - applications view 
- CLI - terminal (MacOS) or cmd (Microsoft)

## Communicating with computers
- GUI - icons, windows, mouse 
- CLI - type commands into black screen

## Windows vs linux
- linux uses CLI, free/open source, servers, and highly customizable.
- windows uses GUI, paid, desktops/laptops, and limited control.

## Open-source software
- softare that anyone can look, use, change, and share.
