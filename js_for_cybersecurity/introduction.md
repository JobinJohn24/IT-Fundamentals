# Course objectives & goals

- describing the role of fundamental web languages, & protocols (including HTML, Javascript, IP, DNS, HTTP)
- explaining core web security constructs (e.g. same-origin policy, cookies, & sessions)
- identifying and analyzing web attacks (cross-site request forgery, cross-site scripting, server-side request forgery, & ReDoS)
- recognizing and assessing risks related to JS supply chain attacks
