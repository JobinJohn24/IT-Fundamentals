### Cursor Changing

- claude/cursors are embedded within VSCode. 
- able to describe the feature you want in natural langugage.
- reads entire codebase -> writes changes -> diffs against existing code with permission enabled to keep you in the loop without having full-permission allowed.
- Provides a shift from writing code to reviewing & directing code.

### Unit testing with AI-coding assistant

- unit tests help analyze a functions expected behavior, choosing inputs, edge cases, & failure cases.
- AI may expose missing logic
- unit testing methods:
  1. Read the function.
  2. Identify what inputs it accepts.
  3. Identify what outputs it should return.
  4. Find each code path.
  5. Create examples for normal cases.
  6. Create examples for edge cases.
  7. Create examples for invalid cases.
  8. Write tests using a framework like pytest, unittest, or Jest.
